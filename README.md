# LED Presence

LED Presence is a planned Python Flask web application with a browser-based frontend interface.

## Project status

The project is in its initial setup phase. Application code, frontend assets, dependencies, and tests will be added as development progresses.

## Planned stack

- Python
- Flask
- HTML, CSS, and JavaScript

## Getting started

Clone this repository and open its directory:

```sh
git clone https://github.com/orlin369/led_presence.git
cd led_presence
```

Create a Python virtual environment:

```sh
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Or on macOS/Linux:

```sh
source .venv/bin/activate
```

Dependency installation and application startup instructions will be added when the Flask application is implemented.
