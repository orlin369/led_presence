# Roboto fonts

Unmodified variable TrueType fonts from:
https://github.com/google/fonts/tree/main/ofl/roboto
Downloaded 2026-10-28. Roboto[wdth,wght].ttf is stored as
Roboto-Regular.ttf; Roboto-Italic[wdth,wght].ttf as Roboto-Italic.ttf.
Both include weights 100–900.

Copyright and SIL Open Font License 1.1 are included in OFL.txt.
These fonts are served locally; no system font installation is needed.
